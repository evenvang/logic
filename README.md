# 逻辑判断 600 题

这是一个纯静态答题网页，可以直接托管到 GitHub Pages。

## GitHub Pages 上传方式

把本文件所在文件夹里的所有内容上传到 GitHub 仓库根目录：

- `index.html`
- `styles.css`
- `app.js`
- `data/`
- `assets/`
- `.nojekyll`

不要只上传 `index.html`，也不要只上传 `logic-quiz.zip`。

上传后在仓库 Settings -> Pages 中选择：

- Source: Deploy from a branch
- Branch: main
- Folder: /root

发布后访问：

`https://你的用户名.github.io/仓库名/`

## 使用说明

答题记录和错题本保存在当前浏览器本地。换设备或清理浏览器数据后，记录不会自动同步。
